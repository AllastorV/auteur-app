# Auteur — product principles

Auteur brings screenwriting, story cards, storyboarding, and worldbuilding into one desktop project. Its web client supports collaboration on that work.

The primary audience is writers and filmmakers who spend long sessions at the page and need a reliable handoff from script to visual plan. The interface supports English and Turkish.

## Working principles

- The page remains the center of attention; controls stay close without crowding it.
- Script, PDF, and analysis use the same pagination rules. The familiar screenplay estimate is roughly one page per minute.
- User work must survive editing, crashes, and recovery. A failed save must be visible, never silent.
- Document formatting must survive export. Geometry and indentation are project data, not decorative styling.
- Collaboration permissions are enforced on the server, not just hidden in the interface.

Supported writing formats include screenplay, television, stage play, radio play, novel, comic, and plain text. Changing a document type must not discard its text.

Visual direction: a precise, quiet editing instrument—dark workspace, bright page, restrained amber accents. The design should support sustained work rather than compete with it.
